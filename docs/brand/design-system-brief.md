# Area 01 — Design inputs (D0 synthesis)

**Date:** 2026-08-21  
**Gate:** `DESIGN_INPUTS_READY`

## Visual brief

Yellow Music United should feel like an **independent music company with a creative studio soul** — editorial, warm, human, professionally art-directed. Not SaaS, not Wix template, not admin dashboard.

## Preservation (from Phase 1)

- Logo identity, yellow association, sunflower/founder photography, Starlight studio story, navigator voice.

## OBSERVED yellow family

`#F7C006`, `#F7CC39`, `#F6B33B`, `#FFD261`, `#ffcd00`, `#FFF2D4`

## Working brand yellow (prototype)

**`#F7C006`** — central observed value; strong accent; reversible pending owner confirmation.

## Typography decision

| Role | Font | Rationale |
|------|------|-----------|
| Primary sans | **Raleway** | Body, navigation, buttons and labels, as on the live Wix site. Lining figures for prices and numbers |
| Display | **Playfair Display** | Headings, quotes and italic accent words, as on the live Wix site |

The earlier rejection of Playfair Display is superseded. The public site follows yellowmusicunited.se (2026-10-30).

## Owner dependencies (non-blocking for preview)

- Vector logo file
- Approved photography originals
- Canonical address

## Refinement pass (2026-08-21)

Visual elevation without changing core brand hex or font families:

- Editorial utilities: accent rules, placeholder art direction, studio atmosphere gradient
- Stronger section rhythm (quiet / expressive spacing)
- Fraunces extended to heading-lg; refined label/eyebrow tracking
- Premium header lockup, nav underline motion, numbered mobile menu
- Image mat frames, grid placeholders, caption treatment
- Booking: accent bar selection, refined slot states, review stripe header
- Cohesive preview narrative flow vs stacked demo blocks

**Fonts at that pass:** Source Sans 3 + Fraunces. The public site later moved to Playfair Display + Raleway.  
**Core yellow unchanged:** `#F7C006` (usage refined via lines, soft surfaces, inset button detail)
